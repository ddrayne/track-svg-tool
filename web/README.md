# TrackFactory Viewer

Local viewer/editor for TrackFactory track outputs. See the [main README](../README.md) for project overview.

## Run locally

Start both the Vite dev server and Express API with one command:

```bash
npm run dev
```

- UI: `http://localhost:5173`
- API: `http://localhost:5174`

The API expects `tf` to be on your PATH. Set `TRACKS_ROOT` and `PORT` env vars to customize.
